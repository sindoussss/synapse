## 8. Explicit Documented Limitations

In accordance with strict certification rules, the following operational constraints are explicitly documented:

1. **`PAYPAL_SANDBOX_VERIFIED`**: PayPal checkout and webhook signature verification are validated against PayPal Sandbox APIs. Live production payment capture requires production PayPal credentials to be configured in `.env`.
2. **`CONTROLLED_TEST_ONLY` Deployments**: Third-party cloud hosting providers (e.g. Vercel, Netlify) utilize local staging adapters and preflight emulators when production API tokens are unset.
3. **`MANUAL_ONLY` Operator Approvals**: High-risk actions (production deployment, contract price modifications, exception overrides) strictly require explicit human operator approval and cannot be automated by autonomous AI agents.
4. **`UNKNOWN` FX Conversion Handling**: Multi-currency accounting strictly isolates currencies (PHP, USD, EUR) without assuming ungrounded foreign exchange conversion rates.
